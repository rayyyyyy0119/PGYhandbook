# 高鉀 Hyperkalemia

**K > 5.0 mmol/L；正常值 3.5–5.0 mmol/L。**

**原因：**腎功能不全／無尿、補太多、輸血、酸中毒、溶血／橫紋肌溶解、Tumor lysis、ACEI/ARB、MRA、NSAID、[[Trimethoprim]]、[[Heparin]]、假性高鉀。

> [!danger] 先做兩件事
> 1. EKG：高聳 T → PR 延長／P 消失 → QRS 增寬 → sine wave → arrest。  
> 2. 判斷假性，但不可因此延誤真正高鉀處置。

## 穩膜 → 轉移 → 移除

| 步驟 | 處置 |
| --- | --- |
| 穩膜 | Calcium gluconate 10% 10 mL；EKG 變化立即給，5–10 分鐘推完，5 分鐘後可重複；CaCl₂ 刺激較強需 CVC |
| 轉移 | RI 0.1 U/kg（Max 10 U）＋D50W 50 mL（血糖 > 250 可不給糖）；Q1H 血糖 × 6 小時 |
| 轉移 | 高劑量 Salbutamol／Bricanyl 霧化；可與 insulin 合用；心臟病注意心搏過速 |
| 轉移 | NaHCO₃ 僅合併代謝性酸中毒時使用 |
| 移除 | Kalimate 起效慢、證據弱；含 sorbitol 灌腸有腸壞死風險 |
| 移除 | Lokelma 10 g TID，約 1 小時起效；或利尿劑；透析是唯一確定有效移除方式 |

| K | 建議動作 |
| --- | --- |
| > 7.0 | Calcium gluconate＋全套降鉀＋腎臟科 H/D，持續 EKG |
| 6.0–7.0 | EKG 變化或不降 → 腎臟科；否則完整三步驟 |
| 5.5–6.0 | Insulin＋Glucose ± 結合劑；停升鉀藥、低鉀飲食，Q4–6H |
| 5.0–5.5 | 檢視藥物飲食，追蹤 |

> [!note] 心跳停止
> 疑似高鉀導致 arrest 時，IV calcium 證據尚不明確；不可延誤高品質 CPR、電擊與 epinephrine。
