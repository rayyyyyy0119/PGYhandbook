# 低鈣 Hypocalcemia

**原因：**大量輸血、副甲狀腺低下、[[Vitamin D]] 缺乏、CKD、急性胰臟炎、Tumor lysis、低鎂、鹼中毒。**症狀：**口周麻木、手足抽搐、Chvostek、Trousseau、QTc 延長、喉痙攣、抽搐。

| 情境 | 處置 |
| --- | --- |
| 有症狀／iCa 明顯低 | Calcium gluconate 1–2 amp（10–20 mL）稀釋後 10 分鐘緩推，可 Q8–12H；每日上限約 8 支 |
| 持續性 | 接續輸注＋[[Vitamin D]]＋口服鈣；同時矯正低鎂 |
| Ca < 6 mg/dL／頑固 | Consult 腎臟科／內分泌科；長期低下驗 PTH |
