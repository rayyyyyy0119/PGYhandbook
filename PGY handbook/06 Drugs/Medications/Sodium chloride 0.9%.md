# Sodium chloride 0.9%

| 情境 | 原始資訊 |
| --- | --- |
| 休克輸液 | 平衡晶體液優於生理食鹽水；大量 0.9% N/S 會造成高氯性代謝性酸中毒；創傷性腦損傷例外建議使用 |
| 高血鈣 | 第一步為 200–300 mL/hr 起，依心腎功能調整，目標尿量 100–150 mL/hr |
| 高血鎂 | 停止來源後，生理食鹽水水化 ± 利尿劑 |
