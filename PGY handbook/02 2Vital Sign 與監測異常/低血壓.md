# 低血壓

- 低血壓：SBP < 90 mmHg 或 MAP < 65 mmHg，或較基準下降 > 40 mmHg。
- 休克：組織灌流不足導致細胞缺氧；低血壓不一定是休克，血壓正常也可能已休克，需看乳酸、尿量、意識、末梢灌流。

## 四大類型

| 類型 | 常見原因 | 臨床線索 |
| --- | --- | --- |
| Distributive | 敗血症、過敏性、神經性 | 末梢溫暖、脈壓大、CVP 低 |
| Hypovolemic | 出血、脫水、大量引流 | 末梢冰冷、頸靜脈塌陷、IVC 塌陷 |
| Cardiogenic | AMI、心律不整、心衰竭惡化 | 頸靜脈怒張、囉音、S3、EKG 異常 |
| Obstructive | PE、Tension pneumothorax、心包填塞 | 頸靜脈怒張但肺野乾淨；需立即處置 |

## 容積評估

SBP < 90 mmHg、MAP < 65 mmHg、CVP < 5 cmH₂O。IVC 內徑 < 2.1 cm 且 > 50% 塌陷 → 傾向體液不足；PLRT 舉腿 45°，SBP／每搏輸出量上升 > 10% → 有輸液反應性；RUSH 一次看心臟收縮、IVC、肺、腹主動脈。

## 2026 指引重點

1. 平衡晶體液優於生理食鹽水；敗血症初始用 [[Lactated Ringer's]]／[[Plasma-Lyte]]。大量 [[Sodium chloride 0.9%\|0.9% N/S]] 可致高氯性代謝性酸中毒；創傷性腦損傷例外用 0.9% N/S。
2. [[Norepinephrine]] 是所有休克（含心因性）的首選升壓劑；[[Dopamine]] 心律不整與死亡率較高，非第一線。
3. 升壓劑可先從周邊靜脈上，不等 CVC；選較粗、近心血管，密切觀察外滲。

## 處置流程

| 步驟 | 處置 |
| --- | --- |
| 1. 快速評估 | 意識、末梢、尿量、乳酸；同時 EKG、CXR、CBC、電解質、腎功能、乳酸、Troponin、A-Gas、培養 |
| 2. Fluid challenge | 年輕人 500 mL 平衡晶體液快速輸注；> 60 歲或心臟不好 250 mL；敗血症目標 3 小時內 30 mL/kg，HF／洗腎個別化 |
| 3. 評估反應 | SBP 上升 > 10 mmHg 或 PLRT 陽性 → 繼續補液；至 1500 mL 仍 SBP < 80–90 → 升壓劑 |
| 4. 目標 | MAP ≥ 65 mmHg、尿量 > 0.5 mL/kg/hr、乳酸下降 |
| 5. 持續低血壓 | 驗 TSH＋Free T4＋Cortisol（± ACTH）；敗血性休克大量升壓可考慮 [[Hydrocortisone]] 200 mg/day |

## 常用升壓／強心劑配置

| 藥物 | 作用 | 配置與用途 |
| --- | --- | --- |
| [[Norepinephrine\|Levophed]]（[[Norepinephrine]]）4 mg/amp | SVR ↑↑、CO ↑ | 濃泡 4 amp/250 mL [[Dextrose 5%\|D5W]] 或 2 amp/100 mL；稀泡 2 amp/250 mL 或 1 amp/100 mL；各型休克首選 |
| [[Vasopressin\|Pitressin]]（[[Vasopressin]]）20 U/amp | SVR ↑ | 10 amp＋[[Dextrose 5%\|D5W]] 250 mL（0.8 U/mL），固定 0.03 U/min；[[Norepinephrine\|Levophed]] 0.25–0.5 mcg/kg/min 未達標時加 |
| [[Epinephrine\|Bosmin]]（[[Epinephrine]]）1 mg/amp | SVR ↑、CO ↑ | 5 amp/500 mL N/S（10 mcg/mL）；過敏性休克第一線 IM 0.3–0.5 mg |
| [[Dopamine]] 200 mg/amp | 低劑量 CO ↑；高劑量 SVR ↑ | 2 amp＋N/S 250 mL（1.6 mg/mL）或預混液；心律不整風險高，非第一線 |
| [[Dobutamine]] 250 mg/amp | CO ↑ | 2 amp＋500 mL N/S（1 mg/mL）；心輸出不足時加，但會降 SVR |

> [!tip] 四句口訣
> 頭昏＝Con's change＝AEIOU TIPS｜胸痛＝r/o ACS｜呼吸喘＝有無 Desaturation → NRM／插管｜休克與低血壓＝灌水 → 升壓＋記 I/O。

不管哪一種，Record I/O、注意尿量。NPO 病人維持性 IVF 約 30 mL/kg/day。
