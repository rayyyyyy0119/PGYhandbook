# 皮膚 Skin

## 皮膚問題快速分流

| 情境 | 處置重點 |
| --- | --- |
| 藥物疹（單純） | 停可疑藥物、抗組織胺、局部類固醇；記錄起疹時間與用藥時序 |
| 壓瘡 | 分期評估、減壓（翻身、氣墊床）、營養支持、傷口照護會診 |
| 蜂窩性組織炎 | 畫線標記範圍與時間、抬高患肢、抗生素；疼痛與外觀不成比例 → 想壞死性筋膜炎 |
| 帶狀疱疹 | 單側皮節分布水泡；72 小時內給抗病毒藥效果最好 |
| 接觸性皮膚炎 | 移除接觸源、局部類固醇、保濕 |

> [!danger] 皮膚紅旗：立即通知後線
> **SJS／TEN：**發燒＋黏膜（口、眼、生殖器）侵犯＋疼痛性紅斑＋Nikolsky sign 陽性 → 立即停可疑藥並會診皮膚科。  
> **DRESS：**用藥 2–8 週後廣泛皮疹＋發燒＋嗜酸性球增多＋肝功能異常。  
> **紫斑不褪色（non-blanching purpura）＋發燒：**想腦膜炎雙球菌血症、DIC。
