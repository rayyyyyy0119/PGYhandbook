# 脹氣與打嗝 Bloating & Hiccup

## 消脹氣

| 順序  | 處置                                                                 |
| --- | ------------------------------------------------------------------ |
| 1   | Menthol packing（擦薄荷油）＋鼓勵下床走動                                       |
| 2   | [[Simethicone\|Gascon（Simethicone）]]一招走天下 |
| 3   | ± [[Metoclopramide\|Primperan]] 或 [[Mosapride]] 促進腸胃蠕動             |

> [!tip] 術後脹氣
> 最有效的處置其實是下床活動，藥物只是輔助。長期臥床＋opioid＋NPO 是脹氣三聯症。

## 止嗝（Anti-hiccup）

| 順序  | 處置                                                                                    |
| --- | ------------------------------------------------------------------------------------- |
| 1   | [[Metoclopramide\|Primperan]]（同時處理胃排空問題）                                              |
| 2   | [[Chlorpromazine\|Wintermin（Chlorpromazine）]]，從 ¼ 或 ½ 顆給起 |
| 3   | ± [[Chlorzoxazone\|Solaxin]]／[[Baclofen\|Befon]]（肌肉鬆弛劑）；頑固者可考慮 [[Baclofen]] 或 [[Gabapentin]] |

> [!danger] [[Chlorpromazine\|Wintermin]] 用藥警語
> 鎮靜作用極強（臨床上曾遇過吃半顆睡三天），且會造成姿勢性低血壓與 QTc 延長。老人、心臟病、譫妄病人格外謹慎，務必從最低劑量給起。

**持續超過 48 小時的頑固性打嗝：**找橫膈刺激（膈下膿瘍、肝腫瘤）、中樞病灶、尿毒症、電解質異常、GERD、藥物（類固醇、BZD）。
