# 值班必備心法

## 1-1 值班必備常數

### Numbers You Must Memorize

| 項目           | 公式／定義                | 備註                                                                     |
| -------------- | ------------------------- | ------------------------------------------------------------------------ |
| 維持性點滴 IVF | 30 mL/kg/day × 體重       | 60 kg ≒ 1800 mL/day ≒ 75 mL/hr。心衰竭、腎衰竭、老年人需下修             |
| 熱量需求 Diet  | 25–30 kcal/kg/day × 體重  | 重症急性期先給 70% 目標熱量即可，不必一次到位                            |
| 胰島素換算     | 1 U RI ↓ 血糖 25–50 mg/dL | 個體差異大，肥胖／胰島素阻抗者效果較差                                   |
| 少尿 Oliguria  | U/O < 0.5 mL/kg/hr        | 60 kg 一班（8 hr）＝ 0.5 × 60 × 8 ＝ 240 mL；實務常以「一班 < 200 mL」抓 |
| 多尿 Polyuria  | > 3000 mL/day             | 或 > 40 mL/kg/day                                                        |
| I/O 可接受範圍 | 非限水：± 500 mL/day      | 限水病人（HF、CKD、SIADH）須依醫囑個別設定                               |

> [!tip] 實戰技巧
> 值班接到「病人尿好像有點少」的電話時，第一件事不是開利尿劑，而是問清楚**幾點到幾點、共幾 mL、體重多少**。很多「尿少」換算後其實在正常範圍，而真正的少尿常常在你追問前已經拖了兩班。

## 1-2 疾病分類三層架構

### Symptom → Organ → System

面對值班電話，把病人的問題放進三個抽屜，思考就不會亂：

| 症狀 | → | 器官 | → | 系統 |
| --- | --- | --- | --- | --- |
| Symptom & Sign<br>燒喘痛暈吐 | → | SOFA score<br>六大器官系統 | → | 8-tion<br>病生理機轉 |

### 第一層：症狀（值班最常被叫的清單）

| 分類 | 症狀 |
| --- | --- |
| 五大主症 | [[發燒\|燒]]、[[呼吸喘\|喘]]、[[疼痛\|痛]]、[[暈]]、[[噁心嘔吐\|吐]] |
| 腸胃道 | [[便祕]]、[[腹瀉]]、[[胃痛]]、[[脹氣與打嗝\|脹氣]]、[[脹氣與打嗝\|打嗝]] |
| 神經精神 | [[失眠\|安眠]]、[[譫妄與躁動\|譫妄]]、[[譫妄與躁動\|躁動]]、[[04 疾病資料庫/04 神經腦血管/癲癇與癲癇重積|癲癇]]、[[腦出血]] |
| 血液 | [[貧血]]、[[DIC]]、[[Coagulopathy]] |
| 其他 | [[尿滯留]]、[[少尿\|尿少]]、[[高血壓]]／[[低血壓]]、[[眼睛]]、[[皮膚]] |

### 第二層：器官（用 SOFA 六大面向盤點）

| 系統     | 評估參數        | 值班意義                                                                                           |
| -------- | --------------- | -------------------------------------------------------------------------------------------------- |
| 呼吸     | PaO₂/FiO₂ ratio | < 300 即 ARDS 範圍，< 100 為重度                                                                   |
| 凝血     | Platelet count  | < 50 k 注意出血；< 20 k 考慮輸注                                                                   |
| 肝       | Total bilirubin | > 2–3 mg/dL 開始出現鞏膜黃染                                                                       |
| 心血管   | MAP／升壓劑劑量 | MAP < 70 即 1 分；需 norepinephrine／epinephrine 為 ≥ 3 分（dobutamine 或低劑量 dopamine 為 2 分） |
| 中樞神經 | GCS             | **< 15 即開始扣分**（13–14 為 1 分）；< 9 考慮插管保護呼吸道                                       |
| 腎       | Creatinine／U/O | U/O < 500 mL/day 已達高分區                                                                        |

> [!note] SOFA 補充
> SOFA 用於評估器官衰竭嚴重度；快速篩檢敗血症惡化風險可併用 NEWS2 等早期警示分數，qSOFA 因敏感度不足已不建議作為單一篩檢工具。[^1]

### 第三層：系統（8-tion 口訣「VPN is CR」）

| 字首  | 機轉                     | 常見例子                           |
| ----- | ------------------------ | ---------------------------------- |
| **V** | Vascular 血管            | CVA、AMI、PE、Aortic dissection    |
| **P** | Perfusion 灌流           | 各型休克、腸繫膜缺血               |
| **N** | Neoplasm 腫瘤            | Tumor fever、Tumor lysis、壓迫症狀 |
| **I** | Infection / Inflammation | 肺炎、UTI、膽道感染、痛風          |
| **S** | Structure 結構           | 阻塞、穿孔、扭轉、疝氣             |
| **C** | Congenital / Chemical    | 電解質、酸鹼、代謝、藥物副作用     |
| **R** | Rheumatoid 自體免疫      | SLE、血管炎、藥物過敏反應          |
