# 急性胸痛 Acute Chest Pain

> [!danger] 五個必須排除的致命診斷
> **AMI（STEMI／NSTEMI）｜Pulmonary embolism｜Tension pneumothorax｜Aortic dissection（Type A）｜Esophageal rupture**

其他鑑別：肺炎、氣胸、心包膜炎／填塞、胸膜積液、胃食道逆流、肌肉骨骼痛、帶狀疱疹。大多數胸痛 survey 起來沒事，但切忌掉以輕心——該做的還是要做。

## 標準處置

1. **10 分鐘內完成 12 導程 EKG**，與過去心電圖比對；有疑慮時做 right-sided 與 posterior leads。
2. **抽血：**hs-cTn、CBC、電解質、腎功能、D-dimer（依 Wells score 決定）、A-Gas。
3. **CXR：**看縱膈腔寬度、氣胸、肺水腫、浸潤。
4. **監測：**上 monitor、建立 IV、給氧（僅 SpO₂ < 90%）、準備 AED。

> [!important] 2026 指引重點｜hs-cTn 快速排除流程[^1]
> ESC 指引建議使用 **0/1 小時或 0/2 小時演算法**快速分流：極低值且症狀 > 3 小時可直接 rule-out；顯著上升或動態變化可 rule-in；介於中間者需再驗並進一步評估。

> [!warning] 兩個常見誤解
> 1. Troponin 上升不等於心肌梗塞：敗血症、腎衰竭、心衰竭、PE、心肌炎皆會上升，需看動態變化與臨床脈絡。
> 2. ACS 不再常規給氧，僅在 SpO₂ < 90% 時給予。

| 懷疑診斷 | 處置 |
| --- | --- |
| STEMI／NSTEMI | 照會心臟內科，討論心導管時機；STEMI 目標 door-to-balloon < 90 分鐘 |
| Pulmonary embolism | CTA 確診；血流動力學不穩定者考慮溶栓或取栓，照會心臟內科／心臟外科 |
| Tension pneumothorax | 不等影像，立即針刺減壓，後續放置 pigtail 或 chest tube |
| Type A dissection | 照會心臟外科緊急手術；控制血壓與心跳（先 β-blocker） |
