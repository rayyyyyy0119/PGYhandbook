# 血氧下降 Desaturation

> [!danger] 最重要提醒
> **心臟不好也會造成 Desaturation，不要只想到肺。**

| 系統 | 鑑別診斷 |
| --- | --- |
| 肺 | Pneumonia、Pleural effusion、Atelectasis、PE、氣胸、痰阻塞、ARDS |
| 心 | 心衰竭／肺水腫、AF RVR、瓣膜疾病（AR、TR、MR）、心肌梗塞 |
| 其他 | 過度鎮靜（opioid、BZD）、呼吸肌無力、疼痛導致淺快呼吸、假性低血氧（探頭鬆脫、末梢冰冷、指甲油、震顫） |

## 五步處置

1. **先確認數值是真的：**換手指、暖手、看波形；同時看病人臉色與呼吸型態。
2. **給氧至目標：**一般 94–98%；COPD 88–92%，不要一味開大。
3. **檢查：**EKG、CXR、A-Gas、床邊肺超音波或心臟超音波。
4. **對因給藥：**支氣管痙攣 → [[Ipratropium-Salbutamol\|Combivent]]；容積過載 → [[Furosemide\|Lasix]]；發炎 → [[Hydrocortisone\|Solu-Cortef]]；痰多 → 抽痰、姿位引流。
5. **無改善：**升級呼吸支持（HFNC／NIV／插管），並通知後線。
