# 便祕 Constipation

> [!warning] 先確認：真的便祕嗎？
> 沒有大便不等於便祕。病人可能 NPO、intake 極差、剛做完大腸鏡清腸，根本沒東西可以大。開藥前先問：平常幾天解一次？這次幾天沒解？有沒有腹脹、噁心、排氣？**有腹脹又沒排氣，先想腸阻塞，不是便祕。**

## 處置階梯

| 階梯 | 處置 |
| --- | --- |
| 1. 起手式 | [[[[Bisacodyl]]\|[[Bisacodyl\|Dulcolax]]（[[Bisacodyl]]）]]口服錠 ± 塞劑；或院內常備刺激性瀉劑（如 Conslife、Through 等，成分依院內品項確認） |
| 2. 加促蠕動 | [[Metoclopramide\|Primperan]]、[[Mosapride]]、[[Domperidone]] |
| 3. 灌腸 | EVAC enema／Glycerin enema（部分需自費） |
| 4. 滲透性瀉劑 | [[Lactulose]]（PO）、[[Magnesium oxide]] 2 tab TID、[[[[Polyethylene glycol]]\|[[Polyethylene glycol\|PEG]]（[[Polyethylene glycol]]）]] |
| 輔助 | 益生菌（Infloran、Antibiophilus）、增加水分與纖維、鼓勵下床活動 |

> [!tip] 實戰提醒
> 灌腸只處理得到降結腸以下的大便；橫結腸以上的宿便只能靠口服瀉劑或促蠕動藥慢慢下來。老人排便無力或糞石嵌塞（fecal impaction），常需 digital disimpaction，光給瀉劑沒用。

**Opioid 引起的便祕：**預防勝於治療，開 opioid 就同時開軟便藥；頑固者可考慮 PAMORA（如 [[Naloxegol]]）。
