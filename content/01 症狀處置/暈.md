# 暈 Dizziness / Vertigo

## 第一步：分清楚是「頭暈」還是「眩暈」

| 類型 | 病人描述 | 常見原因 |
| --- | --- | --- |
| Vertigo | 天旋地轉、有方向感的旋轉 | BPPV（耳石脫落）、Meniere's、前庭神經炎、小腦或腦幹中風 |
| Presyncope | 快暈倒、眼前發黑 | 姿勢性低血壓、心律不整、脫水、出血、藥物 |
| Disequilibrium | 走路不穩、站不住 | 周邊神經病變、小腦病灶、多重用藥 |
| Lightheaded | 暈暈的、講不清楚 | 藥物（Opioid、BZD、降壓藥）、貧血、焦慮、低血糖 |

> [!danger] 最重要的任務：不要漏掉中風
> HINTS 僅適用於「持續性眩暈且有眼震」的病人，不可用於間歇性發作。

| HINTS | 危險（中樞性）表現 |
| --- | --- |
| Head Impulse | 眼球「沒有」修正性跳視 |
| Nystagmus | 方向會變換或垂直性眼震 |
| Test of Skew | 有垂直性偏斜 |

加做指鼻試驗（Finger-to-Nose）、跟脛試驗（Heel-to-Shin），觀察步態與軀幹共濟失調。三項中任何一項屬中樞型，或合併複視、吞嚥困難、單側無力、構音障礙 → **立即安排影像並通知後線**。

## 處理方式

| 情境 | 處置 |
| --- | --- |
| 無中樞性警訊、生命徵象穩定 | [[Diphenhydramine\|Vena（Diphenhydramine）]]1 amp st 或 [[Difenidol\|Cephadol（Difenidol）]]1 tab QID；臥床、床欄拉起、防跌 |
| 合併噁心嘔吐 | 可加 antiemetic（見 [[噁心嘔吐]]） |
| 有眼震但無中樞警訊 | 隔日上班會診 ENT／神內 |

> [!tip] 住院常見原因
> 先量血壓、驗血糖、看藥歷：住院中最常見的「暈」其實是降壓藥過量、脫水與 opioid 副作用。
