# 眼睛 Eye

## 常用眼藥水對照

| 症狀 | 用藥 |
| --- | --- |
| 眼睛痛／結膜炎 | [[[[Sulfamethoxazole]]\|[[Sulfamethoxazole\|Sinomin]]（[[Sulfamethoxazole]]）]]眼藥水 |
| 砂眼 | [[[[Chloramphenicol]]\|[[Chloramphenicol\|CM eye drop]]（[[Chloramphenicol]]）]] |
| 眼睛／眼皮外傷 | [[Gentamicin]] 眼藥膏 |
| 眼睛過敏 | Alminto、Allergopos、Allergocrom |
| 用眼過度痠痛 | [[[[Neostigmine]]\|[[Neostigmine\|O.N.S.D]]（[[Neostigmine]]）]] |
| 人工淚液 | Artelac、Duasorb（可頻繁使用，無防腐劑者更佳） |

> [!danger] 眼睛紅旗：不要自己處理
> 急性視力下降、劇烈眼痛合併頭痛噁心（急性青光眼）、外傷後視力模糊、瞳孔異常、化學品噴濺（先大量沖水至少 15–30 分鐘再說）→ **立即會診眼科。**

> [!warning] 類固醇眼藥水
> 不要隨便開：可能加重單純疱疹角膜炎並造成眼壓升高。
