# 譫妄與躁動 Delirium & Agitation

## 躁動 Agitation

躁動會影響治療，病人可能自拔管路、下床跌倒。插管病人可能 fight ventilator；除鎮靜外可視情況給肌肉鬆弛劑（[[Rocuronium\|Esmeron]]／[[Cisatracurium\|Nimbex]]），但務必確認鎮靜與止痛已足夠，否則等同清醒下癱瘓，是重大醫療傷害。

### 處理原則：先找原因，再給藥

| 步驟 | 處置 |
| --- | --- |
| 1. 排除可逆原因 | 低血氧、低血糖、尿滯留、疼痛、便祕、感染、電解質異常、藥物戒斷 |
| 2. 非藥物介入 | 安撫、環境調整、家屬陪伴、恢復日夜節律、移除不必要管路 |
| 3. 藥物 | [[Haloperidol]] 1 amp（2.5–5 mg）IV/IM；譫妄非戒斷者不給 [[Lorazepam\|Ativan]] |
| 4. 約束 | 可降低傷害，但須符合法規、定期評估記錄並盡早解除 |

> [!warning] [[Haloperidol]]
> QTc 延長與 Torsades de pointes 風險；使用前後建議追蹤 EKG 並矯正低血鉀、低血鎂。注意 EPS、akathisia（易誤判為更躁動而加藥）及 Neuroleptic malignant syndrome。

**酒精戒斷（AWS）躁動相反：**首選 BZD，並用 CIWA-Ar 量表指引劑量。

## 譫妄 Delirium

> [!danger] 核心觀念
> Delirium 是「結果」不是「診斷」，必須處理上游原因：感染、術後、藥物、缺氧、電解質、尿滯留、便祕、疼痛、戒斷。

絕大多數譫妄以低活動型（hypoactive）呈現，只有少數是吵鬧的高活動型；安安靜靜不理人的病人反而更危險、死亡率更高。建議常規使用 CAM／CAM-ICU 或 4AT 篩檢，不憑印象判斷。

### 2026 指引重點：藥物不是主角

- 2025 PADIS 更新：是否用抗精神病藥治療 ICU 譫妄，因證據品質不足，無法贊成或反對。
- 核心是非藥物 ABCDEF bundle：疼痛控制、每日喚醒與自主呼吸試驗、鎮靜選擇、譫妄評估、早期活動、家屬參與。
- [[Haloperidol]] 在 AID-ICU 試驗可能有死亡率助益，但主要結果未達顯著；可用於嚴重躁動危及安全時的症狀控制。
- [[Quetiapine]] 有助眠效果，但部分觀察研究顯示與 ICU 停留延長相關，不建議常規預防。
- 抗精神病藥不能預防譫妄，也不會縮短譫妄天數；處理的是症狀，不是病。

### 實務處置

| 項目 | 做法 |
| --- | --- |
| 找原因 | 感染 survey、血糖、Na/K/Ca/Mg、A-Gas、NH₃、膀胱掃描、藥歷回顧（抗膽鹼、BZD、opioid、類固醇、H2 blocker） |
| 環境 | 白天叫起、拉窗簾、下床；夜間減少干擾；戴回眼鏡助聽器；放時鐘日曆；家屬陪伴 |
| 減藥 | 停不必要鎮靜與抗膽鹼藥，移除不必要管路與約束 |
| 藥物 | [[Quetiapine\|Seroquel]] 12.5–25 mg HS 起（可 BID–QID 調整，高劑量照會精神科）；急性躁動可 [[Haloperidol]] 2.5–5 mg IM/IV |
