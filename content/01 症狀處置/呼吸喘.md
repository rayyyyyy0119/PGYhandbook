# 呼吸喘 Dyspnea

> [!danger] 三個必問重點
> 有沒有 **Desaturation（SpO₂ ↓）**？有沒有 **Wheezing**？有沒有 **Stridor**？

## 鑑別診斷

**COPD／Asthma、Atelectasis（術後極常見）、Pneumonia、Pleural effusion、Pulmonary embolism、AMI（最容易漏掉，務必小心）、心衰竭急性惡化、Anemia、代謝性酸中毒代償。**

## 2026 指引重點：氧氣目標值

| 情境 | 目標 |
| --- | --- |
| 一般急症病人 | SpO₂ 94–98% |
| 有高碳酸血症呼吸衰竭風險者 | SpO₂ 88–92%；包括 COPD、嚴重肥胖、神經肌肉疾病、胸廓變形 |
| 心跳停止 ROSC 後 | SpO₂ 90–98%（PaO₂ 60–105 mmHg）、PaCO₂ 35–45 mmHg、MAP ≥ 65 mmHg |

> [!warning] 氧氣是藥
> SpO₂ > 96% 的常規給氧不但沒有好處，還與死亡率小幅上升相關。氧氣要 titrate，不是開越大越安全。

臨床上「SpO₂ 掉到 94%」在 COPD 病人可能完全正常，在術後第一天的年輕人則是警訊——要看趨勢與基準值，不要只看單一數字。

## 第一步：給氧氣

| 氧氣階梯 | 流量／時機 |
| --- | --- |
| N/C | 2–6 L/min |
| Simple Mask | 6–10 L/min |
| NRM | 10–15 L/min |
| HFNC／NIV | 視適應症 |
| BVM → 插管 | 視適應症 |

> [!warning] 使用提醒
> Simple mask 流量不可低於 5 L/min，否則會有 CO₂ 再吸入問題。NRM 使用前務必先把儲氣袋充飽。

## 第二步：給藥物

| 情境 | 處置 |
| --- | --- |
| 支氣管擴張 | A + B＝[[Ipratropium\|Atrovent（Ipratropium）]]+ [[Terbutaline\|Bricanyl（Terbutaline）]]；C＝Combivent（複方）。A+B 相較 Combivent 較易產生心搏過速 |
| COPD 急性惡化 | A+B／C ＋ 全身性類固醇（[[Hydrocortisone\|Solu-Cortef]] 或 prednisolone 40 mg/day × 5 天）；抗生素視痰量／膿性痰／需通氣支持而定 |
| Asthma | 高劑量吸入型 β2（[[Fenoterol\|Berotec]]／[[Salbutamol]]）＋ [[Ipratropium]] ＋ 全身性類固醇；嚴重者考慮 [[Magnesium sulfate\|MgSO₄]] 2 g IV |
| 喘但 SpO₂ 沒掉 | 很多只給氧氣即明顯改善，不一定要急著給藥。先吸 A+B／C；無改善再 [[Hydrocortisone\|Solu-Cortef]] 1 amp st ± [[Furosemide\|Lasix]] 0.5–1 amp st（懷疑容積過載時） |
| 喘且 SpO₂ 有掉 | 先排除 PE 與 AMI：EKG、CXR、A-Gas、Troponin-I、D-dimer。同時吸 A+B／C ＋ [[Hydrocortisone\|Solu-Cortef]] ± [[Furosemide\|Lasix]] ± [[Epinephrine\|Bosmin]]（INH） |

> [!danger] 紅旗
> **「喘 + SpO₂ 掉 + 血壓掉」＝ massive PE、tension pneumothorax、cardiogenic shock 之一。**不要在病房慢慢試藥；立刻叫人、備插管、通知後線。

## 第三步：插管

> [!warning] 插管前
> 務必先確認有無 DNR／預立醫療決定。

### 插管適應症

| 適應症 | 說明 |
| --- | --- |
| 意識惡化 | GCS < 9，或動作反應下降（如 M6 → M4） |
| 呼吸道阻塞 | Stridor、上呼吸道水腫、大量分泌物無法清除 |
| 氧合失敗 | FiO₂ 100% 下 PaO₂ ≤ 60 mmHg；PaO₂ 61–70 mmHg 可考慮 |
| 通氣失敗 | PaCO₂ 持續上升合併 pH ↓、呼吸型態不佳（Air hunger、肋間凹陷）、持續 RR > 30 且給藥無效 |

### 插管流程

| 步驟 | 內容 |
| --- | --- |
| 1. 備物 | Endo（男 7.5／女 7.0）、喉鏡 3 號、Stylet、Bougie、BVM、抽吸、EtCO₂、備 [[Norepinephrine\|Levophed]] |
| 2. Pre-oxygenation | 面罩密合，用 BVM 把 SpO₂ 拉到 99–100%（至少 3 分鐘） |
| 3. 給藥 | 鎮靜（[[Midazolam\|Dormicum]]；血壓不穩者可選 [[Etomidate]]／[[Ketamine]]）＋肌肉鬆弛劑。[[Rocuronium\|Esmeron（Rocuronium）]]快速誘導建議劑量 1–1.2 mg/kg（60 kg 約 60–70 mg）；等 60–90 秒待完全鬆弛再插 |
| 4. 插管並確認 | EtCO₂ 波形為金標準；再聽診＋CXR 確認深度 |

> [!tip] 插管實戰提醒
> [[Rocuronium\|Esmeron]] 劑量不足會使起效變慢、插管條件變差。沒有給肌肉鬆弛劑時嘴巴很緊、視野差、成功率低；部分醫院病房不備肌鬆劑，此時建議轉 ICU 插管。血壓偏低者插管前先備好升壓劑，避免 peri-intubation collapse。

## 非侵襲性正壓通氣（NIV／BIPAP）

| 項目 | 重點 |
| --- | --- |
| 證據明確有效 | COPD 急性惡化合併呼吸性酸中毒、心因性肺水腫 |
| 限制 | 病人可配合、臉部可密合、意識清楚、能自行清除分泌物 |
| 缺點 | 痰咳不出來可能惡化病情（如肺炎）；延誤插管時機會增加死亡率 |

> [!danger]
> 沒有 DNR 的病人若已達插管標準，請以插管為優先考量，不要用 NIV 拖時間。

## P/F ratio 快速判讀

**P/F = PaO₂ ÷ FiO₂**（FiO₂ 用小數，如 40% 寫 0.4）

| P/F ratio | 判讀 |
| --- | --- |
| > 300 | 正常 |
| 200–300 | 輕度 ARDS |
| 100–200 | 中度 ARDS |
| < 100 | 重度 ARDS |

> [!tip] 快速估 FiO₂
> N/C 每 1 L/min 約 +4%（室內空氣 21% 起算），故 N/C 3 L ≒ 33%。
