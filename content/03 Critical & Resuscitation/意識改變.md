# 意識改變 Consciousness Change

> [!tip] AEIOU TIPS
> **A**lcohol／**E**pilepsy／**I**nsulin（血糖）／**O**piate・Overdose／**U**remia｜**T**rauma／**I**nfection／**P**sychiatric・Poison／**S**troke・Shock・Seizure

1. **ABC＋給氧＋監測，同時立刻驗血糖**：這是唯一可以在 1 分鐘內逆轉的原因。
2. **神經學檢查：**GCS、瞳孔、光反射、四肢動作對稱性、腦膜刺激徵象。
3. **抽血：**CBC/DC、T-bil、AST/ALT、BUN/Cr、Na/K/Ca/Mg、A-Gas、NH₃、血糖；視情況加毒物、藥物濃度、TSH、Cortisol。
4. **影像：**CXR（合併喘者排除肺炎、肺水腫）；Brain CT（與 VS 討論後安排，排除出血與大範圍梗塞）。
5. **紀錄與回查：**I/O、藥歷（鎮靜劑、opioid、抗膽鹼藥、剛加的新藥）。

## 對因治療

| 原因 | 處置 |
| --- | --- |
| 低血糖 | [[Dextrose 50%\|D50W]] 40–50 mL（< 70）／80–100 mL（< 40），15 分鐘後複驗 |
| 低血鈉 | 有神經症狀 → [[Sodium chloride 3%\|3% NaCl]] 100–150 mL bolus over 20 min，Q2–4H 追蹤；見 [[低鈉]] |
| 高血鈉 | [[Dextrose 5%\|D5W]] 或 [[Sodium chloride 0.45%\|0.45% N/S]] 緩慢矯正，每日 ≤ 10 mmol/L，Q4–6H 追蹤；見 [[高鈉]] |
| 高血鈣 | 生理食鹽水水化＋[[Calcitonin]]＋雙磷酸鹽；驗 CK 排除橫紋肌溶解與 Tumor lysis；見 [[高鈣]] |
| 肝性腦病變 | [[Lactulose]] 口服＋灌腸（目標一日 2–3 次軟便）、[[Rifaximin]]；找誘因（感染、出血、便祕、電解質） |
| 代謝性酸中毒 | 找原因（AG 是否上升）；pH < 7.1 時可考慮 [[Sodium bicarbonate\|NaHCO₃]]，但矯正原因才是重點 |
| 低血氧 | 給氧、排除 PE（D-dimer、Troponin、CTA）；已給高濃度氧仍 PaO₂ ≤ 60 mmHg 考慮插管 |
| Opioid 過量 | 針狀瞳孔＋呼吸抑制 → [[Naloxone]] 0.04–0.4 mg IV 分次給；一次給太多會誘發戒斷與劇痛 |
| CVA | 照會神經內科；缺血性中風不要積極降壓（除非要溶栓）；出血性依 [[腦出血]] 目標 |
