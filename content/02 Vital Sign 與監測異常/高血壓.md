# 高血壓 Hypertension

## 分類（2025 AHA/ACC）

| 分類 | 血壓值 |
| --- | --- |
| 正常 | < 120／< 80 mmHg |
| 血壓偏高 Elevated | 120–129／< 80 mmHg |
| 第一期高血壓 | 130–139／80–89 mmHg |
| 第二期高血壓 | ≥ 140／≥ 90 mmHg |
| 高血壓急症／重度高血壓 | ≥ 180／≥ 120 mmHg |

2025 AHA/ACC 維持 130/80 mmHg 作為診斷與治療門檻，以 PREVENT 風險方程式指引藥物決策，並提升居家血壓量測（HBPM）在診斷上的地位。

> [!danger] 值班最容易做錯的事
> 住院中「無症狀」血壓升高不應常規給降壓藥，尤其靜脈注射。超過 66,000 位住院長者研究顯示，積極降壓反而增加 AKI、心肌損傷、中風與低血壓，未改善預後；高達 69% 的 IV [[Hydralazine]] 使用缺乏適當適應症。

## 接到「血壓 180」的流程

| 步驟 | 處置 |
| --- | --- |
| 1. 確認量測 | 壓脈帶尺寸、手臂位置、剛活動／情緒激動，重測一次 |
| 2. 問器官損傷症狀 | 胸痛、呼吸困難、劇烈頭痛、視力改變、神經缺損、少尿；有 → 高血壓急症 |
| 3. 找可逆原因 | 疼痛、尿滯留、焦慮、失眠、缺氧、便祕、戒斷、漏吃原降壓藥 |
| 4. 都沒有 | 記錄、觀察、恢復原口服藥，隔天由主治團隊調整長期處方 |

## 常用口服降壓藥

| 類別 | 藥物 |
| --- | --- |
| PRN 常給 | [[Captopril\|Capoten]]（[[Captopril]], ACEI）、[[Nifedipine\|Atanaal]]（[[Nifedipine]], CCB） |
| 常規 CCB | [[Amlodipine\|Norvasc（Amlodipine）]]、[[Nifedipine\|Adalat OROS（Nifedipine 長效）]] |
| ARB／ACEI | [[Valsartan\|Diovan]]（[[Valsartan]]）、[[Captopril\|Capoten]] |
| α-blocker | [[Doxazosin\|Doxaben]]（[[Doxazosin]]）；男性合併 BPH 一舉兩得 |
| 複方／其他 | [[Sevikar]]、[[Exforge]]、[[Hydralazine\|Apresoline]]（[[Hydralazine]]） |

**用藥順序：**C > A，B 少給（除非合併 CAD、HF、心律不整），D（利尿劑）不常於急性期使用。短效 [[Nifedipine]] 舌下已淘汰，會造成血壓劇烈波動、反射性心搏過速與缺血事件。

## 特殊疾病血壓目標

| 情境 | 目標 |
| --- | --- |
| 急性缺血性中風（未溶栓） | SBP > 220 或 DBP > 120 mmHg 才降；第一天僅降約 15% |
| 急性缺血性中風（要溶栓） | 溶栓前 < 185/110 mmHg；後 24 小時 < 180/105 mmHg |
| 自發性腦出血 | SBP 150–220 者目標 130–150 mmHg，平順達標 |
| 急性主動脈剝離 | SBP < 120 mmHg、HR < 60 bpm；先 β-blocker 再血管擴張劑 |
| 主動脈瘤 | SBP < 120 mmHg |
| CAD 心導管術後 | SBP < 140 mmHg |
| 急性肺水腫 | [[Nitroglycerin]] 為主；同時給氧、利尿、必要時 NIV |
| 子癲前症／子癲症 | SBP < 140 mmHg；[[Magnesium sulfate\|MgSO₄]] 預防抽搐 |

## 高血壓急症

| 分類 | 定義與處置 |
| --- | --- |
| Emergency | BP ≥ 180/120 mmHg＋急性標的器官損傷 → ICU、靜脈可滴定藥物 |
| 無症狀重度高血壓（舊稱 Urgency） | BP ≥ 180/120 mmHg、無器官損傷 → 不需急降，口服調整＋門診追蹤 |

**標的器官損傷：**高血壓腦病變、腦出血／梗塞、急性心衰竭／肺水腫、ACS、主動脈剝離、AKI、子癲症、微血管溶血性貧血、視乳突水腫。

> [!warning] 降壓原則
> 第一小時 MAP 降約 20–25%；之後 2–6 小時至約 160/100 mmHg；24–48 小時逐步正常化。不可急降到正常。例外：主動脈剝離（20 分鐘內 SBP < 120）、子癲症、嗜鉻細胞瘤危象需更快；缺血性中風除非溶栓，否則不積極降。

### 常用靜脈藥物

| 藥物 | 用法 | 注意事項 |
| --- | --- | --- |
| [[Nicardipine]]（[[Nicardipine\|Perdipine]]） | 原汁 push 1–3 mL；或 5 amp/50 mL run 5 mL/hr；或 3 amp/100 mL run 10 mL/hr | 多數情境首選；反射性心搏過速；剝離先 β-blocker |
| [[Labetalol]]（[[Labetalol\|Trandate]]） | 0.5–1 amp（10–20 mg）slow IV push，每 10 分鐘可重複 | 作用 4–6 小時；可能 180 直接掉至 80；氣喘、心搏過緩、高度 AV block 禁用 |
| [[Nitroglycerin]] | 持續輸注滴定 | ACS 或急性肺水腫首選；頭痛、耐受性 |
| [[Esmolol]] | 持續輸注 | 主動脈剝離首選，超短效 β-blocker |
| [[Hydralazine]]（[[Hydralazine\|Apresoline]]） | 5–10 mg IV | 作用不可預測、反射性心搏過速，不建議第一線；孕婦例外 |
