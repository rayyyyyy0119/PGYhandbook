# 少尿 Oliguria

**定義：U/O < 0.5 mL/kg/hr（或一班 < 200 mL／8 hr）。**

## 評估與處置

| 步驟            | 重點                                                         |
| ------------- | ---------------------------------------------------------- |
| 1. Post-renal | 床邊超音波掃膀胱與腎臟，找水腎／尿滯留；確認 Foley 阻塞或折到                         |
| 2. Pre-renal  | BUN/Cr > 20；FeNa < 1%（利尿劑或代謝性鹼中毒時不準，改 FeUrea < 35%）        |
| 3. 藥歷         | NSAID、ACEI/ARB、顯影劑、[[Vancomycin]]、[[Amphotericin B]]、利尿劑過量 |
| 4. 對因         | Post-renal → 導尿／JJ／PCN；Pre-renal → 補液；Renal → 支持治療         |

> [!warning] 利尿劑治不好 AKI
> 無法預防或治療 AKI，也不改善恢復或死亡率；角色是處理容積過載。[[Furosemide]] stress test 1–1.5 mg/kg IV，2 小時尿量 < 200 mL 者進展至透析風險較高。加速啟動 RRT 未改善死亡率，反增透析依賴。

**透析絕對適應症 AEIOU：Acidosis 難矯正、Electrolyte（頑固高鉀）、Intoxication、Overload（利尿劑無效肺水腫）、Uremia（心包炎、腦病變）。**

## 利尿劑用法

| 方式 | 做法 |
| --- | --- |
| Bolus | [[Furosemide\|Lasix]] 1 → 2 → 4 amp，每次間隔 1–2 小時；評估 U/O > 0.5 mL/kg/hr；4 支仍無效聯絡腎臟科準備透析 |
| Continuous | 10 amp 原汁（20 mL），run 0.5–1 mL/hr，Max 4 mL/hr；先 loading bolus 再 infusion |
| 效力轉換 | [[Bumetanide]] 1 mg ≒ [[Furosemide]] 40 mg PO ≒ 20 mg IV（來源介於 1:20–1:40）；[[Bumetanide\|Burinex]] 規格依廠牌確認 |
| 副作用 | 耳毒性、低血鉀、低血鈉、低血鎂、代謝性鹼中毒、脫水 |

> [!danger] 紅旗
> 尿少＋高血鉀：[[Furosemide\|Lasix]] 無效不要一直加藥，盡快聯絡腎臟科安排透析，同時依高血鉀流程處理。
