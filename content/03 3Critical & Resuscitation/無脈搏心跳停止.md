# 無脈搏心跳停止 Cardiac Arrest

## 五步驟備戰口訣

1. **區分活死人：**10 秒內確認頸／股動脈脈搏，同時看有無正常呼吸。
2. **準備來壓胸：**無脈搏立即壓；100–120/min、深度 5–6 cm、完全回彈、30:2、中斷 < 10 秒。
3. **摳人來幫忙：**999／急救小組／二線值班。
4. **推東西備物：**急救車、去顫器、BVM、插管用具；同步抽血、做心電圖。
5. **準備來插管：**男 7.5／女 7.0，3 號喉鏡，衛生紙墊肩。

## 2025 AHA 指引重點[^1]

- 單一 Chain of Survival：不再區分成人／兒童、院內／院外。
- IV 優先於 IO；IV 失敗或不可行時才用 IO。
- 不常規使用機械式 CPR；人工壓胸困難或危險時才考慮。
- Vasopressin 單用或加在 Epinephrine 上皆無額外好處。
- Double sequential 與 vector change 電擊用於難治性 VF 的效益尚未確立。
- 不建議 Head-up CPR（研究以外）。
- 成人異物哽塞：5 次背部拍擊＋5 次腹部推擠交替。
- 心房顫動／撲動同步電擊初始能量提高至 ≥ 200 J。

> [!danger] 死人流程口訣
> **只電兩個：pVT／VF。PEA／Asystole 不可電擊。**

| 節律 | 流程 |
| --- | --- |
| VF／pVT（可電擊） | ① 立即不同步電擊：雙相波依機型，多為 120–200 J；單相波 360 J；充電時持續壓胸，不需先 check pulse。② 電完立即壓胸 2 分鐘，再 check rhythm。③ [[Epinephrine]] 1 mg IV，首次電擊未成功後開始，每 3–5 分鐘一次。④ [[Amiodarone]] 300 mg IV push（第三次電擊後），可追加 150 mg；或 [[Lidocaine]] 1–1.5 mg/kg。⑤ 處理 5H5T。 |
| PEA／Asystole（不可電擊） | ① 立即 [[Epinephrine]] 1 mg IV，越早越好，每 3–5 分鐘重複。② 高品質 CPR，每 2 分鐘 check rhythm。③ 全力找原因；PEA 多由低血容與低血氧引起。 |

## 可逆原因 5H5T（進階版 6H6T）

| 5H | 5T |
| --- | --- |
| Hypovolemia 低血容 | Tension pneumothorax 張力性氣胸 |
| Hypoxia 低血氧 | Tamponade 心包填塞 |
| Hydrogen ion 酸中毒 | Toxins 毒物／藥物 |
| Hypo/Hyperkalemia 血鉀異常 | Thrombosis（pulmonary）肺栓塞 |
| Hypothermia 低體溫 | Thrombosis（coronary）冠狀動脈栓塞 |

**6H6T：**再加 Hypoglycemia 低血糖與 Trauma 創傷。口訣：**「三低鉀高酸中毒、二心二肺毒藥物」**。

## 急救常見 Q&A

| 問題 | 答案 |
| --- | --- |
| 去顫器顯示 pVT／VF，要先 check pulse？ | 不用，直接電擊；充電過程持續壓胸 |
| Epinephrine 第幾次電擊後？ | 可電擊：首次電擊未成功後；不可電擊：越早越好 |
| Amiodarone 第幾次電擊後？ | 第三次後，300 mg IV push，可追加 150 mg |
| 壓胸中心律改變，要 check pulse？ | 不用，壓滿 2 分鐘（120 秒）再 check |
| 要壓多久才能停？ | 依可逆原因、初始心律、ETCO₂ 趨勢與臨床脈絡；ETCO₂ 單一數值不可作終止依據 |

## ROSC 後照護

| 項目 | 目標 |
| --- | --- |
| 氧合 | SpO₂ 90–98%（PaO₂ 60–105 mmHg），避免高氧 |
| 通氣 | PaCO₂ 35–45 mmHg（除非嚴重酸血症） |
| 血壓 | MAP ≥ 65 mmHg，避免低血壓 |
| 血糖 | 避免 < 70 與 > 180 mg/dL |
| 體溫控制 | 32–37.5°C，至少 36 小時；適用未依指令反應者 |
| 檢查 | 12 導程 EKG；考慮心臟超音波與頭至骨盆 CT；未清醒者做 EEG |
| 預後 | 多模式評估，至少 ROSC 後 72 小時（或回到正常體溫後）再判斷 |
