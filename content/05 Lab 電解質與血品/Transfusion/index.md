# 輸血與血品 Transfusion

> [!tip] 快速對照
> **LPR → Hb｜FFP → INR｜Cryo → Fibrinogen｜PH → Platelet**

## PRBC／LPR｜紅血球

**適應症：**矯正貧血。

### 2026 指引重點：紅血球輸注閾值[^1]

| 族群 | Hb 閾值 |
| --- | --- |
| 一般住院、血流動力學穩定 | < 7 g/dL（限制型策略，強建議） |
| ICU、消化道出血 | < 7 g/dL |
| 血液腫瘤科 | < 7 g/dL |
| 心臟手術、骨科術後 | < 7.5–8 g/dL |
| 急性心肌梗塞 | 寬鬆策略，目標約 10 g/dL（AABB 2025，依 MINT） |

> [!danger] 不要只看數字
> 限制型策略在絕大多數情境下與寬鬆型死亡率相當，卻大幅減少輸血相關風險與血品消耗，因此成為預設做法。但務必併同評估症狀（胸悶、心搏過速、低血壓）、共病、出血速度與病人意願再決定。

| 項目 | 重點 |
| --- | --- |
| 製備 | 台灣一單位由 250 mL 全血製備 |
| 效果 | 成人約 2 U 提升 Hb 1 g/dL |
| 老人／心衰竭 | 每袋 3–4 小時慢速輸注，避免 TACO；必要時輸前給 [[Furosemide\|Lasix]] |

## FFP｜新鮮冷凍血漿

**適應症：**活動性出血或侵入性處置前 INR > 1.5–2、大量輸血、DIC。**劑量約 10–15 mL/kg。**

> [!warning] 不宜只因 INR 輕度上升輸注
> 不建議僅因 INR 輕度上升預防性輸注；效果有限，且增加 TACO／TRALI。

**[[Warfarin]] 緊急逆轉：**[[4-factor PCC]]＋[[Vitamin K]] 優於 FFP；DOAC 使用專一逆轉劑。

## Cryoprecipitate／Cryo｜冷凍沉澱品

**適應症：**Fibrinogen 低下（DIC、大出血、產科出血）。

| 項目 | 重點 |
| --- | --- |
| 一次劑量 | 10 U |
| 活動性／產科出血目標 | Fibrinogen > 150 mg/dL |
| 一般情境 | Fibrinogen > 100 mg/dL |
| 其他成分 | vWF、Factor VIII、Factor XIII |

## Platelet／PH｜血小板

台灣有傳統血小板濃厚液與分離術血小板（Apheresis platelet, PH）。

> [!tip] 單位換算
> **1 U PH ≒ 12 U 傳統血小板。**若院內非 PH 品項，開立時記得寫 12 U。

### 血小板輸注閾值

| 情境 | 閾值 |
| --- | --- |
| 預防性、穩定 | < 10,000/µL |
| 發燒／敗血症／凝血異常 | < 20,000/µL |
| 活動性出血、一般侵入性處置 | < 50,000/µL |
| CNS 或眼科手術 | < 100,000/µL |

## 輸血反應

| 反應 | 辨識與處置 |
| --- | --- |
| 急性溶血反應（ABO 不合） | 初期發燒、腰痛、血紅素尿、低血壓 → 立刻停輸、保留血袋、通知血庫、大量輸液維持尿量 |
| TACO | 呼吸困難、高血壓、JVD、BNP 上升 → 停輸、給氧、利尿劑；老人最常見 |
| TRALI | 6 小時內急性低血氧、雙側浸潤、血壓偏低、無容積過載 → 支持治療，多需通氣支持 |
| 過敏／類過敏 | 蕁麻疹可給抗組織胺後續輸；喉頭水腫／休克 → 停輸、[[Epinephrine]] |
| 發燒性非溶血 | 最常見，體溫上升 ≥ 1°C；先排除溶血與感染再續輸 |

> [!danger] 大量輸血
> 注意低鈣（檸檬酸）、高鉀、低體溫、凝血病變——「致命三角」。
