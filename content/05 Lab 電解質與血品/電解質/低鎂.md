# 低鎂 Hypomagnesemia

**Mg < 1.7 mg/dL。原因：**GI loss、利尿劑、酒精、PPI 長期使用、Amphotericin B、Cisplatin、Refeeding syndrome。

低鎂會造成頑固低鉀、低鈣，增加 Torsades de pointes 風險。

| 情境 | 處置 |
| --- | --- |
| 一般 | MgSO₄ 1–2 g IV，1 小時輸注 |
| TdP 等緊急 | MgSO₄ 2 g，10–15 分鐘給 |
| 輕度 | 可口服補充，但易腹瀉 |
| 腎功能不佳 | 減量 |

> [!tip] 補鉀補不起來、QTc 拉長、不明原因抽搐 → 驗鎂、補鎂。
