# 低鉀 Hypokalemia

**K < 3.5 mmol/L。原因：**嘔吐／腹瀉、利尿劑、低鎂、代謝性鹼中毒、insulin、β2 agonist、Refeeding syndrome。

| K | 處置 |
| --- | --- |
| < 3.5 | Radi-K 2 PC TID 或口服 KCl |
| < 3.0 | Radi-K 2 PC TID＋KCl 20 mEq st |
| < 2.5 | KCl 20 mEq Q8H IVD＋口服；點滴可換 [[Taita No.3]] |
| < 2.0 | KCl 20 mEq Q6H IVD＋T3 baseline，Q6H K、持續 EKG |
| < 1.5 | 更積極 IV（需 CVC＋監測）、Q4H K、積極找原因 |

> [!danger] 補鉀三大安全守則
> 周邊濃度 ≤ 40 mEq/L、速率 ≤ 10 mEq/hr；更快需 CVC＋EKG。每日一般 ≤ 200 mEq。補不上先驗 Mg；低鎂不補，鉀補不進去。腎功能不佳、少尿者格外謹慎，至少 QD／Q12H 追蹤。
