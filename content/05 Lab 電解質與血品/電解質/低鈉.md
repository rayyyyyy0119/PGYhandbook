# 低鈉 Hyponatremia

| 分級 | Na |
| --- | --- |
| 輕度 | 130–134 mmol/L |
| 中度 | 125–129 mmol/L |
| 重度 profound | < 125 mmol/L |

**原因：**SIADH、Thiazide、心衰竭／肝硬化／腎病症候群、腎上腺功能不全、甲狀腺低下、多渴、術後低張輸液。

## 3% NaCl 快速間歇 Bolus

| 情境 | 做法 |
| --- | --- |
| 重度症狀：抽搐、昏迷、嘔吐、心肺窘迫 | 3% NaCl 100–150 mL IV，20 分鐘內推完；最多重複 3 次；首小時 Na 上升 4–6 mmol/L，症狀改善即停 |
| 中度症狀：頭痛、噁心、意識混亂 | 可考慮單次 bolus，同時診斷與病因治療 |
| 無症狀／慢性 | 限水、停致病藥、治療病因；不需 3% NaCl |

> [!danger] 矯正上限
> 24 小時上升：高風險 ≤ 8 mmol/L，一般最多 10 mmol/L；48 小時 ≤ 18 mmol/L。ODS 高風險：慢性、Na < 120、低鉀、酒精、營養不良、肝病、低磷。

**監測：**急性期 Q2–4H；矯正過頭可 [[Dextrose 5%\|D5W]] ± [[Desmopressin\|DDAVP]] 拉回。
